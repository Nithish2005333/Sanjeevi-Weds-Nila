# Sanjeevi-Weds-Nila

A digital wedding invitation web application celebrating the wedding and reception of **Sanjeevi & Nila**.

## Features
- **Royal Split Envelope Opening Modal**: Traditional wax seal with ambient entrance animation.
- **Background Flute Music Controller**: "Narumugaye Narumugaye" flute cover with play/pause controls.
- **Hero Cover & Family Blessings**: Traditional South Indian heritage aesthetic with custom typography.
- **Interactive Save the Date**: Calendar integration with direct `.ics` download.
- **Wedding & Reception Celebrations**: Interactive celebration cards with Google Maps location links.
- **Couple Scroll Join Section**: Animated groom & bride avatars meeting on scroll.
- **Traditional Tamil Invitation**: Full Tamil wedding invitation details with direct call contact buttons.
- **WhatsApp Rich Link Previews**: Optimized OpenGraph card metadata with custom gold medallion thumbnail.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the invitation in your browser.
